## json文件格式
- dict：`{"姓名": "张三", "年龄": 18}`
- list：`["张三", "李四"]`
- 字符串：`"张三李四王五"` （注意，必须有双引号）
- 纯数字：`123`
**注意**：字典格式的key一定得是字符串，如果没有加引号等不符合标准字典格式则也会报错

## json load和loads的用法

json load/loads是将json格式的数据转成python对象
load是对文件进行操作的，因此load的主要参数是打开的文件，调用格式通常为 load(f)

loads是对字符串进行操作的，因此loads的主要参数是字符串，调用格式通常为 load(str)
