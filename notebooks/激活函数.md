激活函数的作用，本质上是给网络引入**非线性**

激活函数大致分为：
- **输出概率相关**
	- Sigmoid
	- Softmax
	- LogSigmoid
	- LogSoftmax
- **传统饱和型**
	- Tanh
- **Relu家族**
	-  ReLU
	- Leaky ReLU
	- PReLU
	- ReLU6
- **平滑改进型**
	- ELU
	- SELU
	- Softplus
	- Swish / SiLU
	- GELU
	- Mish

## Sigmoid
公式：
![[Pasted image 20260418173734.png]]
图像：
![[Pasted image 20260418175813.png]]
### 图像特征

- 经典 **S 型曲线**
- 当 x→+∞时，输出趋近 1
- 当 x→−∞时，输出趋近 0
- 在 0 附近变化较快，两端逐渐饱和

### 值域

(0,1)

### 特点

1. 输出可以直接解释成“概率”
2. 平滑、连续、可导
3. 不是零中心函数，输出始终为正
4. 两端容易进入饱和区，梯度很小，容易出现**梯度消失**

### 适用场景

- **二分类输出层**
- 多标签分类中每个标签独立预测概率
- 各种门控结构里也常见，例如：
    - LSTM 的输入门、遗忘门、输出门
    - 注意力或门控单元里的开关系数

### 注意事项

- **不适合深层隐藏层** 作为默认激活函数，因为梯度消失明显
- 输出是概率时，通常配合 **Binary Cross Entropy** 使用
- 如果实现二分类，很多框架更推荐直接用 **BCEWithLogitsLoss**，因为它把 Sigmoid 和交叉熵合并了，数值更稳定

## LogSigmoid
公式：
![[Pasted image 20260418174036.png]]
图像：
![[Pasted image 20260418175747.png]]
### 图像特征

- 单调递增
- 始终小于 0
- 当 x 很大时接近 0
- 当 x 很小时趋向负无穷

### 值域

(−∞,0)

### 特点

1. 本质上是对 Sigmoid 结果取对数
2. 在涉及对数似然时更自然
3. 数值稳定性通常比先算 sigmoid 再取 log 更好

### 适用场景

- 某些概率模型、对数似然计算
- 负采样、对比学习、能量模型中偶尔会看到
- 框架内部的稳定实现中较常见

### 注意事项

- 它通常**不是隐藏层的常规激活函数**
- 更多是出现在**损失计算**或某些概率表达中

## Softmax
对于向量 $\mathbf{z}= (z_1,z_2,...,z_n)$，第 i个分量：
![[Pasted image 20260418174505.png]]

### 图像特征

- 它不是单变量曲线，而是**向量到概率分布的映射**
- 会把一组实数压成一组非负数，并且总和为 1
- 较大的输入分量会被放大成更高概率

### 值域

每个分量都在：(0,1)

且满足分量和等于1

### 特点

1. 输出是一个**概率分布**
2. 适合“多类互斥分类”
3. 对最大值非常敏感
4. 指数运算可能造成数值不稳定

### 适用场景

- **多分类任务输出层**
- 语言模型下一词预测
- 注意力机制里把相关性分数转成权重
- 分类器最后一层的概率化输出

### 注意事项

1. **Softmax 通常用于输出层，不用于隐藏层**
2. 实际实现时通常会做数值稳定处理：
![[Pasted image 20260418175157.png]]

3. 在 PyTorch 这类框架里，做多分类训练时一般直接用 **CrossEntropyLoss**，因为它内部已经包含了 **LogSoftmax + NLLLoss**，不需要你手动先 Softmax
4. Softmax 假设类别互斥；如果类别不互斥，通常应改用多个 Sigmoid

### 图像特征

- 也是向量映射，不是普通单变量曲线
- 输出为对数概率
- 最大的那个分量最接近 0，其余更小、更负

2. 比“先 Softmax 再 log”更数值稳定
3. 常用于损失计算

### 适用场景

- 分类模型训练内部
- NLLLoss 前一层
- 语言模型中的对数概率计算

### 注意事项

- 一般不是拿来单独当“隐藏层激活函数”
- 更多是为了**数值稳定地做概率建模**

## Tanh
公式：
![[Pasted image 20260418182215.png|160]]
图像：
![[Pasted image 20260418182331.png]]
### 图像特征

- 也是 **S 型曲线**
- 与 Sigmoid 类似，但关于原点对称
- 中心穿过 (0,0)

### 值域

(−1,1)

### 特点

1. **零中心**
2. 比 Sigmoid 更适合隐藏层一些
3. 两侧同样会饱和，仍然会有**梯度消失**

### 适用场景

- 早期神经网络隐藏层
- RNN / LSTM 中的候选状态更新常用 Tanh
- 需要输出在 $[−1,1]$ 范围时

### 注意事项

- 深层网络中，隐藏层默认通常已不再首选 Tanh
- 但在循环神经网络和某些受限输出场景里仍很常见

## ReLU
公式：
![[Pasted image 20260418182421.png]]
图像：
![[Pasted image 20260418182445.png]]
### 图像特征

- 左边全为 0
- 右边是斜率为 1 的直线
- 在 0 点处不可导，但实际训练不影响使用

### 值域

$[0,+∞)$

### 特点

1. 计算非常简单
2. 正区间梯度恒为 1，缓解梯度消失
3. 会产生稀疏激活，很多神经元输出为 0
4. 负半轴梯度为 0，可能导致**神经元死亡**（dead ReLU）

### 适用场景

- CNN、MLP 中最经典的隐藏层激活函数
- 很多视觉任务的老牌默认选择

### 注意事项

- 输入长期落在负区间时，该神经元可能再也学不回来
- 不零中心
- 在 Transformer 中通常已不是主流，更多用 GELU / SiLU

## Leaky ReLU
公式：
![[Pasted image 20260418182613.png]]
其中$\alpha$一般是一个很小的常数，如0.01

图像：
![[Pasted image 20260418182706.png]]
### 图像特征

- 正半轴同 ReLU
- 负半轴不是 0，而是有一个很小斜率的直线

### 值域

(−∞,+∞)

### 特点

1. 缓解 dead ReLU 问题
2. 负半轴仍有梯度
3. 比 ReLU 稍微灵活

### 适用场景

- 希望保留 ReLU 简洁性，但又不想负区间完全失活时
- 一些 CNN/MLP 场景

### 注意事项

- 负斜率 α\alphaα 需要经验设置
- 效果常常比 ReLU 更稳，但未必总是更强

- 计算量比 ReLU 大

- 比 ReLU 计算更慢
- 作为普通隐藏层默认激活并不主流

PyTorch 中常叫 **SiLU**。

### 图像特征

### 适用场景

- 现代 CNN
- 一些轻量模型和检测模型
- 需要比 ReLU 更平滑的场景

### 注意事项

- 计算比 ReLU 略贵
- 工程上很常见，尤其在较新的视觉模型中
