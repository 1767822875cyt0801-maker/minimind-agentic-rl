**这个文件是一个本地命令行聊天客户端。**它不是在调用 OpenAI 官方云服务，而是在用 OpenAI 的调用格式调用本地服务。  (为了复用现成 SDK 和生态，统一接口，降低接入成本)
作用：
给已经部署好的 MiniMind 推理服务，提供一个最小可用的交互式聊天入口。
用指定的 MiniMind 模型，带着最近几轮对话，按照给定的生成参数，向本地服务发起一次聊天请求；如果开了流式输出，就一边生成一边返回；如果开了 thinking，就连思考内容也一起返回

- 连接一个 **OpenAI 兼容接口** 的本地服务；
- 在终端里循环读取用户输入；
- 把输入包装成 `messages=[{"role": ..., "content": ...}, ...]` 这种聊天格式；
- 调用 `client.chat.completions.create(...)` 发起推理请求；
- 把返回结果打印出来；
- 把这轮问答继续写回历史，供下一轮对话使用。
